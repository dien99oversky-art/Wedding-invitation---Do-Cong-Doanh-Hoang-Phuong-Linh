# THIỆP CƯỚI ONLINE — ĐỖ CÔNG DOANH & HOÀNG PHƯƠNG LINH

## Cách chạy
Mở `index.html` bằng trình duyệt.

## Đăng lên GitHub Pages miễn phí
1. Tạo tài khoản GitHub.
2. Tạo repository mới, ví dụ: `thiep-cuoi`.
3. Upload toàn bộ file và thư mục `assets`.
4. Vào Settings → Pages → Deploy from branch → chọn `main` / `root`.
5. GitHub sẽ cấp link dạng `https://tenban.github.io/thiep-cuoi/`.

## Nhạc nền
Website đã có nút bật/tắt nhạc. Để dùng nhạc, đặt file MP3 của bạn tên chính xác là:
`music.mp3`
ngay cạnh `index.html`.

## Lưu ý
- Hai nút Google Maps đang tìm kiếm theo địa chỉ bạn cung cấp; nếu có link vị trí chính xác, hãy thay URL trong `index.html`.
- Nút RSVP hiện mở email mặc định. Có thể đổi sang Google Form hoặc Zalo sau.
- Ngày cưới được đặt là 20/09/2026 lúc 13:00 theo thông tin đã cung cấp.
